# ГРР-Контроль

Программа управления буровыми и геологоразведочными работами для ООО «Производственно-Буровая Компания».

Это веб-приложение: сервер + браузерный интерфейс. Работает на компьютере, телефоне и планшете, устанавливается как обычное приложение (PWA).

---

## 1. Что нужно установить на компьютер

**Node.js версии 20 или новее** — https://nodejs.org (берите версию LTS).
Больше ничего не нужно: база данных встроенная (SQLite, файл `data.db` рядом с проектом), внешние сервисы не требуются.

Проверить, что Node установлен:

```bash
node -v
```

Должно вывести что-то вроде `v20.11.0`.

---

## 2. Первый запуск

Откройте папку проекта в терминале (командной строке) и выполните по очереди:

```bash
npm install       # установка библиотек, один раз, занимает 1-3 минуты
npm run dev       # запуск в режиме разработки
```

После запуска откройте в браузере: **http://localhost:5000**

Вход: логин `director`, пароль `director`.

В режиме `npm run dev` любое изменение в коде сразу видно в браузере — страницу перезагружать не нужно.

---

## 3. Рабочий (боевой) запуск

```bash
npm run build                          # сборка
NODE_ENV=production node dist/index.cjs  # запуск
```

На Windows в PowerShell:

```powershell
npm run build
$env:NODE_ENV="production"; node dist/index.cjs
```

## 5. Как вносить изменения

**Поменять текст, подпись, заголовок** — найдите нужный файл в `client/src/pages/` и правьте текст прямо в кавычках. Сохранили — в браузере обновилось.

**Поменять цвета** — `client/src/index.css`, переменные в начале файла.

**Добавить колонку в таблицу базы:**
1. Добавьте поле в нужную таблицу в `shared/schema.ts`
2. Добавьте обработку в `server/storage.ts`
3. Выведите колонку на экране в соответствующем файле `client/src/pages/`

**Добавить новый раздел без программирования** — этого делать не нужно в коде: в самой программе есть создание пользовательских разделов (Настройки → Разделы программы).

**Изменить разбор сводок** (если поменяется форма на участке) — `server/pbkparse.ts`. Там для каждого типа сводки описано, как ищется строка заголовков и какие колонки к чему относятся.

## 6. Резервное копирование

Вся база — один файл `data.db`. Скопируйте его — это полная резервная копия.
Восстановление: положите файл обратно на то же место и перезапустите программу.

Дополнительно в самой программе есть выгрузка всех данных в Excel.

---

## 7. Учётные записи

Демонстрационные доступы (логин совпадает с паролем): `director`, `analyst`, `geolog`, `lab`, `supply`, `viewer`.

**Смените пароли перед рабочим запуском.** После смены подсказка на экране входа исчезает автоматически.

Если случайно удалили всех директоров — при следующем запуске программа сама создаст учётную запись `director` с паролем `director`.

## 8. Размещение в интернете

Сейчас программа опубликована на https://pbk-control.pplx.app

Разместить у себя можно на любом хостинге, где работает Node.js: VPS, Timeweb, Selectel, Reg.ru и подобных. Нужно: скопировать проект, выполнить `npm ci --omit=dev`, `npm run build` и запустить `node dist/index.cjs`. Порт по умолчанию 5000.

Для постоянной эксплуатации несколькими людьми рекомендуется вынести базу с локального диска на управляемую СУБД (PostgreSQL) — встроенная SQLite подходит для прототипа и небольшой нагрузки.

## 9. Технологии

React + TypeScript + Vite + Tailwind CSS + shadcn/ui на стороне браузера, Express + Drizzle ORM + SQLite на сервере, exceljs и xlsx для работы с Excel, bcrypt для паролей.
